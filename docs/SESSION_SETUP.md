# Настройка из окна

Карточка агента → «Настроить» показывает программу CLI и каталог профиля. Поиск программ пассивный. «Проверить версию и вход» запускает только диагностические команды выбранного CLI; ограничения описаны в [CLI_CHECK.md](CLI_CHECK.md).

Для Claude добавлена кнопка «Создать тестовую сессию». Она доступна только если фоновый клиент сообщает поддержку новой операции и постоянного режима Claude. Старый клиент не получает подставной команды регистрации: окно прямо сообщает, что его требуется обновить.

Создание записывает новый точный UUID, адрес сессии, выбранные программу/профиль и отдельную папку `workspaces/<uuid>` внутри каталога данных. Оно не запускает модель, не отправляет письмо и не меняет разрешение на вызовы CLI. Рабочие и GUI-чаты не используются. Выбор существующей сессии, login/logout и постоянные адаптеры остальных провайдеров остаются отдельными этапами.

Настройка сохраняется одной транзакцией. Недопустимые пути не оставляют частичную запись. Повтор одного запроса подтверждает ту же запись; другие настройки под прежним адресом или новая привязка к уже зарегистрированной сессии отклоняются. При потере ответа окно сохраняет исходный запрос в памяти для явного повтора. После полного закрытия окна нужно сначала проверить список сессий: одинаковый адрес не может создать вторую сессию. Технический UUID в интерфейсе не требуется вводить или публиковать.

Готовность профиля и созданная запись не означают, что модель уже работает. Пока запуск моделей не разрешён, письма сохраняются в очереди. Включение запуска, обработка писем и безопасное завершение владельца — следующие проверки. Установка новой оболочки сама по себе не заменяет уже работающий фоновый процесс.

Для следующей проверки подготовлен [запуск только выбранной сессии](SCOPED_LAUNCH.md), чтобы не обрабатывать старые письма других адресатов. Это изменение после preview.18; кнопка включения модели в текущем выпуске ещё отсутствует.
