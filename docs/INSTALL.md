# Установка Agent Messenger

Для обычного использования Mac-приложения начните с [скачивания и установки Agent Messenger.app](MAC_APP.md). Доступен технический preview для macOS 15+ на Apple Silicon. Windows, Linux и Intel Mac получат отдельные пакеты после проверки установки и обновлений; готовых загрузок для них пока нет.

Ниже описан отдельный архив командного клиента для разработчиков и тестирования. Это другой формат пакета; команды этой страницы не нужны для установки `.app`.

## Из проверенного архива

1. Скачайте архив и сверяемую контрольную сумму из доверенного места. Сумма, приложенная неизвестным отправителем к неизвестному файлу, не подтверждает происхождение.
2. Сверьте SHA-256 архива, распакуйте его в отдельный каталог. В нём выполните `shasum -a 256 -c SHA256SUMS` и `./messenger version`. Метаданные также лежат в `manifest.json`.
3. Выполните `./messenger install`. По умолчанию версия размещается в `~/.local/lib/agent-messenger/`, а `~/.local/bin/messenger` указывает на неё. Можно задать `--prefix /абсолютный/пользовательский/каталог`.
4. Добавьте каталог `bin` в PATH самостоятельно при необходимости. Установщик не меняет настройки оболочки, не запускает клиент/модель, не выполняет вход и не устанавливает службу.
5. Дальнейшая работа — [локальный клиент](CLIENT.md), [фоновый запуск](BACKGROUND.md), [окно](LOCAL_UI.md). Без разрешения моделей запуск не вызывает CLI. Для первой пробы нужен отдельный тестовый каталог и тестовые сессии.

Не нужен sudo. Пакет имеет локальную ad-hoc подпись, без Developer ID и notarization. Его запуск после загрузки браузером с проверками Gatekeeper пока не принят; никаких команд снятия защиты или quarantine пакет не предлагает. Это ограничение перед публичным распространением, а не пройденная проверка установки у нового пользователя.

## Обновление

Новая версия устанавливается той же командой из нового проверенного архива. Бинарники лежат в отдельных каталогах по версии и SHA-256, предыдущий не перезаписывается. Ссылка переключается атомарным переименованием. При повторной установке той же сборки проверяется содержимое существующего файла.

Переключение защищено общими блокировками клиента и запуска CLI. Работающий клиент, незаконченный запуск, любой сохранённый резерв CLI или пустой/повреждённый реестр запрещают установку. Установщик **не останавливает процессы и не очищает резервы**. Следуйте существующей процедуре безопасного завершения/восстановления. В текущем прототипе это может ограничивать обновление до решения жизненного цикла владельца; обход не добавляется.

Очередь, исходящие, история и профили находятся отдельно от программы. Установщик не открывает и не переносит SQLite. Запуск следующей версии может выполнять её документированные изменения схемы. Старая версия бинарника сохранена, но её запуск не является откатом базы; совместимость произвольного понижения версии не обещается. Чужой файл `bin/messenger` или ссылка на чужой продукт не заменяются.

## Сборка пакета из исходников

Из корня проверенного состояния репозитория:

```sh
go run ./cmd/package-preview \
  --version 0.0.0-preview.1 \
  --revision ПОЛНЫЙ_SHA_ИСТОЧНИКА \
  --out /абсолютный/каталог/сборок
```

Параметр `--revision` — заявленный сборщиком commit SHA; программа не удостоверяет соответствие произвольно изменённых локальных файлов этому SHA. Перед выпуском требуется отдельно сверить чистое состояние исходников. Не используйте условный SHA тестового пакета как номер настоящего выпуска.

Сборщик вызывает Go без shell, встраивает версию/ревизию, использует `-trimpath -buildvcs=false`, подписывает нативный бинарник ad-hoc, проверяет запуск команды `version` и создаёт tar.gz, manifest, SHA-256 бинарника и отдельную сумму архива. В пакет входят инструкции и документация. Существующий архив с тем же именем не перезаписывается. Загрузка или публикация в GitHub автоматически не выполняются.

Для проверенной здесь связки Go 1.22.2/macOS использован `--external-linker` и установленный инструмент сборки Apple. В остальных сборках по умолчанию `CGO_ENABLED=0`. Можно задать `--go /точный/путь/к/go`. Инструменты Go/Apple нужны сборщику; пользователю готового архива они не нужны. CI сохраняет тестовые архивы только после проверок установки и обновления; сборщик и исходный SHA записаны в метаданных. Битовая воспроизводимость, отдельная аттестация происхождения и подпись разработчика ещё не приняты. Для новых сборок используйте поддерживаемую стабильную версию Go; 1.22.2 оставлена в CI как проверка совместимости исходников.
