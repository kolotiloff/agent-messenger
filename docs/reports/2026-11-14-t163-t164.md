# T-163 settings controls and T-164 first-run welcome

Date: 2026-11-14. Branch: `codex/t163-theme-switch`, based on main after the 0.70 release record. Published in [0.71](https://github.com/kolotiloff/agent-messenger/releases/tag/v0.0.0-preview.71).

## Reproduction and correction

T-163: opening settings and clicking the visible «Тёмная» option timed out because `settings-dialog` intercepted pointer events. Select popovers were appended outside their modal dialog and became inert. Place each popover inside its closest dialog (or the application root for non-modal controls). Both theme and language selection use this path. No color palette or native appearance persistence logic changed.

The earlier T-154 screenshot exercise set `data-theme` directly and only opened the menu; it did not select a theme through the menu. That was an interaction coverage gap. The new browser check uses real pointer/keyboard input for selection and asserts the resulting palette and saved choice.

T-164: `renderThread` returned a separate «Создайте проект» panel before it could render the welcome introduction. It now reuses welcome for the first launch, adds a project-creation step, and keeps coordinator setup unavailable until a project exists. The empty task pane is hidden before a project; at 600 px it previously covered the welcome's create button. Existing projects retain the normal task-pane toggle.
