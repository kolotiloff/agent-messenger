# Настройка сессии из окна на Mac

6 ноября 2026. Продуктовая реализация preview.18, коммит `5c8e4eb`. Реальные модели и рабочие чаты не запускались.

## Проверка окна

Отдельные временные HOME, профиль, каталог данных и локальный клиент с постоянным режимом Claude, без разрешения вызовов модели. CLI заменён небольшим тестовым исполняемым файлом с журналом команд.

Из карточки Claude открыта настройка. Явная проверка показала версию и подтверждённый вход тестового CLI. Затем введено имя тестовой сессии и нажата кнопка создания. Диалог закрылся; переписка открылась на новой сессии с пустой историей.

После этого в SQLite ровно одна сессия в режиме `new` и одно событие `setup_new_claude`. Писем, попыток, ответов и постоянных запусков нет. Очередь осталась на паузе, вызовы модели не разрешены. Рабочая папка создана внутри тестового каталога данных. Журнал тестового CLI содержит только `--version` и `auth status --json` — по одному вызову на каждую из двух явных диагностических проверок (HTTP и окно). Ответ диагностики не содержит контрольный email из вывода CLI.

## Автоматические проверки

Проверены атомарность записи, восемь одновременных одинаковых запросов, отказ при подмене существующей привязки, повтор после начала обработки без изменения состояния, запрет внешнего workspace и symlink-каталога. HTTP-проверки покрывают авторизацию, Origin, неизвестные поля, повреждённые и составные JSON, запрет произвольных аргументов, ограничение одновременной диагностики и сокрытие её внутренних ошибок.

Полный локальный набор с проверкой гонок, форматированием и vet на Mac прошёл. Проверка реального CLI, отправка модельного сообщения, постоянные Codex/Cursor и обновление работающего фонового клиента в эту приёмку не входят.

Для этого коммита также прошли все четыре задания GitHub Actions: Mac/Linux на Go 1.22.2 и stable. Проверялись race, vet, компиляция целей и тестовых бинарников; Mac stable дополнительно собрал и проверил preview-пакеты и жизненный цикл оболочки без GUI. Запуск Windows-продукта этим не подтверждён. [Результат CI](https://github.com/kolotiloff/agent-messenger/actions/runs/42192877048).

## Установленное приложение

Подписанный preview.18 опубликован в GitHub Releases и установлен на этот Mac. Версия и ревизия встроенного бинарника совпадают с выпуском. После обновления приложения полный снимок базы совпал с предыдущим: 6 сессий, 13 писем, 10 попыток и 9 ответов.

Затем отдельно обновлён фоновый клиент. Перед этим подтверждено `cli_launch=not-authorized`, сохранены локальная резервная копия SQLite и файл защитных резервов. Старый процесс завершён штатной командой; новый запущен обычным путём `desktop`, с тем же каталогом данных, без разрешения моделей. После запуска подтверждены пауза, 6 удерживаемых сессий и 3 ожидающих письма. Сессии, письма, попытки, ответы, постоянные запуски и записи восстановления не изменились; файл резервов побайтно прежний. Журнал получил записи перезапуска и паузы. Защитные резервы не снимались.

В установленном окне после обновления статусов доступна кнопка создания новой тестовой сессии Claude. Эта ручная приёмка обновления не означает, что автоматическое обновление работающего клиента уже реализовано. Новая модельная сессия в пользовательской базе не создавалась и письма из старой очереди не запускались.
