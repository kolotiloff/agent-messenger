# Update 17: download recovery and margins

Date: November 6, 2026.

## Cause

After the window was restarted, a leftover downloader still held the channel lock. The next check wrongly reported GitHub as unavailable. An HTTP check of GitHub succeeded at that moment. After the download finished, preview.16 was installed via Sparkle; the full inspect summary before and after matched. Real models were not run.

## Changes

- A held lock is returned as a separate successful result `busy`; an error opening the lock is not treated as busy.
- The window waits for an existing download with bounded retries, without seizing someone else's lock. An available version is labeled «Доступно обновление» ("Update available").
- Visible version: «Предварительная версия N» ("Preview version N"); the exact version is available in a tooltip.
- Margins account for the space the scrollbar actually occupies: WebKit may draw it as an overlay, while Chromium may reserve separate space. A fixed 6-pixel scrollbar thumb is no longer subtracted when the occupied width is zero.

## Checks before publishing

Full scripts/check.sh on the Mac (Go 1.27.3): formatting, modules, vet and race tests passed. Swift typecheck passed. A test of the update-fetch command confirms state=busy without releasing someone else's lock. A separate test distinguishes a corrupted lock path from a held lock.

In a browser with the real assets and synthetic data: left/right card margins 16/16, the version label is readable.

## Acceptance on the Mac

Preview.17 was installed from the published GitHub package via Sparkle. In the real WebKit window, symmetric outer card margins and «Предварительная версия 17» ("Preview version 17") are visible. The full inspect summary before/after matched; the background client PID did not change, and model calls remained forbidden.

A separate test process held only the update downloader lock. A manual check showed «Загружается обновление…» ("Downloading update…") without a GitHub error. After the lock was released, the window automatically resumed the check and showed that the installed version is up to date. Protective session reservations were not changed.

GitHub Actions 42189401316: all four Mac/Linux jobs on Go 1.22.2/stable passed. This is not acceptance of the Windows runtime or of models.
