Agent Messenger для Linux (предварительная версия)

Как запустить
1. Распакуйте архив:  tar -xzf agent-messenger-*-linux-*.tar.gz
2. Запустите окно:    ./messenger open
   Окно откроется в браузере по умолчанию. Если браузер не открылся,
   программа напишет путь к файлу, который нужно открыть в браузере.
   Пока команда работает, страница доступна. Ctrl+C закрывает только
   страницу: клиент и задачи продолжают работать в фоне.

Установить в ~/.local/bin (по желанию):  ./messenger install
Затем окно открывается командой:          messenger open

Агенты
- Claude Code и Codex ищутся в PATH, в ~/.local/bin, /usr/local/bin и /usr/bin.
- Cursor пока не поддерживается.

Данные лежат в ~/.local/share/agent-messenger (или в $XDG_DATA_HOME).
Остановить фоновый клиент: messenger shutdown

Обновления на Linux пока не приходят сами: скачайте новый архив со
страницы выпусков и замените файл messenger, когда клиент остановлен.
