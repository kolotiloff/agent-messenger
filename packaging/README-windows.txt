Agent Messenger для Windows (предварительная версия)

Как запустить
1. Распакуйте архив в любую папку, например в «Документы\Agent Messenger».
2. Дважды щёлкните messenger.exe.
   Windows может предупредить, что программа не подписана: нажмите
   «Подробнее», затем «Выполнить в любом случае».
3. Откроется окно консоли, а в браузере — окно Agent Messenger.
   Пока консоль открыта, страница работает. Закрытие консоли закрывает
   только страницу: клиент и задачи продолжают работать в фоне.
   Чтобы вернуться в окно, снова запустите messenger.exe.

Агенты
- Claude Code: нужна обычная установка, которая даёт claude.exe
  (обычно %USERPROFILE%\.local\bin\claude.exe).
- Codex: установка через npm подходит, программа найдёт codex.exe внутри
  пакета. Файлы .cmd и .bat не запускаются: укажите путь к .exe.
- Cursor пока не поддерживается.

Данные лежат в %LOCALAPPDATA%\AgentMessenger.
Остановить фоновый клиент: messenger.exe shutdown (в консоли из этой папки).

Обновления на Windows пока не приходят сами: скачайте новый архив со
страницы выпусков и замените файл messenger.exe, когда клиент остановлен.
