Любые команды

Для всех агентов этого компьютера. Агент выполняет любые команды без подтверждения и без песочницы, с доступом к сети, и может менять файлы за пределами папки проекта.

И для задач с других компьютеров

Задачи, которые сюда отправили координаторы других компьютеров сети, тоже выполняются с любыми командами. Если выключить, такие задачи идут с проверками разрешений агента.

Проекта пока нет. Создайте его в списке проектов слева.

Этот компьютер

Принимать задачи других компьютеров

Координаторы других компьютеров сети смогут запускать здесь исполнителей. Задача выполняется в папке проекта с тем же именем на этом компьютере.

Отдавать журнал по сети

Координаторы других компьютеров сети смогут прочитать конец журнала программы на этом компьютере, чтобы разобраться с ошибкой. Идентификаторы сессий, коды и ключи из него убираются.

Сервер на этом компьютере

Этот компьютер подключён к другому серверу. Чтобы запустить свой, сначала отключитесь от него.

Доступ

Адрес, по которому этот компьютер виден из интернета: белый IP или домен, при другом внешнем порте — через двоеточие. Порт на роутере направьте на этот компьютер сами. Из интернета подключаются только по длинному коду.

Автообновление

Новая версия ставится сама, когда на этом компьютере нет задач. Пока ждёт, компьютер не берёт новых задач.

Отзыв о программе

Снимок окна: вставьте его (⌘V или Ctrl+V) или перетащите сюда

Отзыв сохраняется на этом компьютере вместе с версией программы. Все отзывы можно выгрузить одним файлом здесь или попросить об этом координатора.

Передали файл? Выгруженные отзывы можно удалить.

Настройки агента

Cursor берёт инструменты только из своего файла ~/.cursor/mcp.json. Перед первой задачей Messenger добавит туда одну запись messenger_task; ваши записи не меняются. В обычных сессиях Cursor у неё нет инструментов.

Изменения сохраняются сами.
