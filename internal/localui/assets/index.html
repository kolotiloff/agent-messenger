Настройка агента

Cursor берёт инструменты только из своего файла ~/.cursor/mcp.json. Перед первой задачей Messenger добавит туда одну запись messenger_task; ваши записи не меняются. В обычных сессиях Cursor у неё нет инструментов.

Программа и профиль агента. Проверка показывает версию и вход, не открывая разговор с моделью.

Пишите названия точно так, как их принимает сам агент. Координатор сможет выбрать только модель из этого списка; если список пуст, задачи идут на модели по умолчанию.

Любые команды

Исполнитель запускает любые команды без подтверждения и без песочницы, с доступом к сети, как вы сами в терминале. Он может изменить или удалить файлы и за пределами папки проекта. Действует для новых задач этого агента на этом компьютере.
